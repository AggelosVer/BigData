ΟΔΗΓΙΕΣ ΕΚΤΕΛΕΣΗΣ ΕΡΓΑΣΙΑΣ (BIG DATA PIPELINE)

Προαπαιτούμενα:
1. Εγκατεστημένο Docker Desktop (ανοιχτό).
2. Εγκατεστημένη Python 3.x.
   Εγκατάσταση απαραίτητων βιβλιοθηκών στην Python:
   pip install kafka-python flask pymongo

Όλες οι εντολές εκτελούνται από τον φάκελο "Code" της εργασίας.

-------------------------------------------------------------------------
ΒΗΜΑ 1: Εκκίνηση Υποδομής (Docker)
-------------------------------------------------------------------------
Ανοίξτε ένα τερματικό (Terminal 1 - PowerShell) και εκτελέστε:

1. (Προαιρετικά) Καθαρισμός από προηγούμενες εκτελέσεις:
   docker-compose down --volumes

2. Εκκίνηση των containers (Redpanda, MongoDB, Spark Master/Worker):
   docker-compose up -d

3. Δημιουργία του Kafka topic (απαιτείται μόνο την πρώτη φορά):
   docker exec -it redpanda rpk topic create vehicle_positions

-------------------------------------------------------------------------
ΒΗΜΑ 2: Ερώτημα 1 - Παραγωγός (Producer)
-------------------------------------------------------------------------
Ανοίξτε ένα ΔΕΥΤΕΡΟ τερματικό (Terminal 2) και εκτελέστε:

   py producer.py -n 2

(Ο producer θα ξεκινήσει να στέλνει δεδομένα κίνησης στο topic `vehicle_positions`).

-------------------------------------------------------------------------
ΒΗΜΑ 3: Ερώτημα 2 & 3 - Κατανάλωση & Αποθήκευση (Spark)
-------------------------------------------------------------------------
Ανοίξτε ένα ΤΡΙΤΟ τερματικό (Terminal 3) και εκτελέστε:

   docker-compose up spark-submit-job

(Το Spark job θα συνδεθεί στον Redpanda, θα επεξεργάζεται τα δεδομένα,
θα τα τυπώνει στην οθόνη σε Batches και θα τα αποθηκεύει στη MongoDB).

# Έλεγχος αποθηκευμένων δεδομένων στη MongoDB (PowerShell):

# 1. Εμφάνιση μίας ενδεικτικής εγγραφής στιγμιαίων στατιστικών (stats)
docker exec -it mongo mongosh --eval "db.getSiblingDB('traffic').getCollection('stats').findOne()"

# 2. Εμφάνιση μίας ενδεικτικής εγγραφής χρονικών παραθύρων (windowed stats)
docker exec -it mongo mongosh --eval "db.getSiblingDB('traffic').getCollection('windowed_stats').findOne()"

# 3. Υπολογισμός συνολικού μέσου όρου ταχύτητας ανά δρόμο (από τα στιγμιαία stats)
docker exec -it mongo mongosh --eval "db.getSiblingDB('traffic').getCollection('stats').aggregate([{`$group: {_id: '`$link', avg_overall_speed: {`$avg: '`$vspeed'}}}])"

# 4. Υπολογισμός συνολικού μέσου όρου ταχύτητας ανά δρόμο (από τα windowed stats)
docker exec -it mongo mongosh --eval "db.getSiblingDB('traffic').getCollection('windowed_stats').aggregate([{`$group: {_id: '`$link', avg_overall_speed: {`$avg: '`$avg_speed'}}}])"

-------------------------------------------------------------------------
ΒΗΜΑ 4: BONUS - REST API
-------------------------------------------------------------------------
Ανοίξτε ένα ΤΕΤΑΡΤΟ τερματικό (Terminal 4) και εκτελέστε:

   py api.py

(Το API θα σηκωθεί στο http://localhost:5000).
